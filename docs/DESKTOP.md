# Windows 伴随窗口

0.4.1 使用独立 Electron 透明窗口，鼠标穿透、不主动抢焦点，并提供托盘与展开读符窗口。不是官方 Pet 或 Codex 背景替换。

源码运行需 Node.js 22+：在项目根目录执行 `npm ci`，然后 `npm start`。自动接收消息还需按 [PLUGIN.md](PLUGIN.md) 构建、安装并审阅信任插件。打包后的 `Summoning-Fu.exe` 自带 Electron 运行时；插件 hook 仍需本机 Node.js。

常用入口：

```powershell
npm start -- --read
npm start -- --motion-preview
npm start -- --hide
npm start -- --quit
```

启动器优先使用最新桌面包，找不到时使用已安装的开发 Electron。修改源码后重新打包，或确认正在启动的构建与源码一致。单实例交接用于避免出现多份伴随进程。

“展开读符”显示当前冻结的完整内容和来源。“预览完整动效”打开独立本地窗口，不改写真实任务状态、待展示队列或来源顺序。没有真实上下文时明确使用本地示例。旧的离线 HTML 符体演示不等于正常 hook 接入测试。

正常入口与预览均完整播放约 14 秒：纸 650ms、字 2100ms、定形 250ms、完整保持 10 秒、淡出 1 秒。本应用不跟随系统减少动态，不改 Windows 设置。隐藏停止逐帧绘制；睡眠取消当前展示，恢复后等待新事件。多屏、全屏及实际睡眠恢复尚未完成本阶段真机验收。

“选择会话文件”是只读的手动绑定路径，用于查看受支持的本机 rollout；它不证明自动 hook 成功，也不应当将普通日志当可信事件随意导入。手动选择同样受版本和会话身份检查约束。

退出不会卸载 hook；停用、卸载见 [PLUGIN.md](PLUGIN.md)。本窗口的入场与收起均不代表模型完成、失败或费用消耗。
