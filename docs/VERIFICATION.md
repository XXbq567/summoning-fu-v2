# 验证范围与未完成项

本文件概括 0.4.1 阶段状态，不附个人机器记录、原始日志或截图。它不将单元测试、夹具和真实客户端验收混为一谈。

## 此前实现阶段已执行

实现主代理报告：97 项自动检查通过，离线预览构建通过。自动检查涵盖符体、时间线、字段来源、会话与 turn 隔离、旧事件与取消保护、文件边界、CLI 精确版本、预览隔离及遥测清洗等。这个数量属于此前实现阶段；公共源码导出会重新验证，导出专项检查可能增加数量，最终以发布记录为准。

Windows x64 实机完成实际 hook 脚本 stdin → 本地夹具事件 → Electron 窗口的三条路径验证：普通路径、本地 drive namespace、经物理目录身份核验的应用目录 alias。观察到系统减少动态 true、有效策略 false；正常入口约 5 秒后出现，完整播放 14 秒，未抢焦点，隐藏后停止绘制。普通路径包含纸、部分字、完整保持、淡出的自然阶段截图检查。正常入口没有借助预览或 seek 完成这些观察。

完整保持阶段有持续观测与 10 秒时间线边界检查。共享源码中隐藏、睡眠取消及过期不复活还有自动检查，但这些不能代替所有系统状态下的真机验证。

## 公开源码复核

维护者发布前应在干净导出目录重新执行 `npm ci`、`npm test`、`npm run build`，并检查桌面与插件打包。构建环境、最终检查数量、commit 与 release tag 由对应发布记录填写；本文件不编造尚未生成的标识。

本存档不提供可直接重放的真实用户事件，也不复制内部 QA JSON、PNG 或 rollout。合成测试中的身份和内容是测试数据，不能作为用户真实工作证据。
