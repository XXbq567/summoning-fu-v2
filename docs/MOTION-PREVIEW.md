# 完整动效预览

在项目根目录双击 `PREVIEW-MOTION.cmd`，或执行：

```powershell
npm start -- --motion-preview
```

读符窗口和托盘菜单也有“预览完整动效”。预览独立播放当前符的冻结副本；没有当前上下文时使用明确标注的本地示例，不伪造真实来源、不发送聊天或模型请求。

依次显纸 650ms、显字 2100ms、定形 250ms、完整停留 10 秒、轻缩淡出 1 秒。可暂停、继续、重新播放或停在阶段查看。隐藏或最小化时暂停；关闭销毁该预览，重开重新播放。

0.4.1 正常入口也采用同样完整动效，不需要以预览作为替代。系统偏好仅独立显示，Windows 设置保持不变。共享渲染器仍有通用减少动态能力，但当前产品策略不采用该模式。

中文字符使用字体字形按序显现，未声称任意汉字逐笔书写或完整 Unicode 字体覆盖。预览通过只能证明预览路径；正常 hook 与自然用户提交需各自验收。
